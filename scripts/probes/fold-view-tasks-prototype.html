设计一：长文折叠成标签，能看全文、能编辑

要素规则
何时折叠一次粘贴 ≥4 行，或超过 1000 个字符，就变成一个标签：[Pasted: 46 lines] 或 [Pasted: 3.9 KB]。原来的线是 10 KB，几段长文（每段几百字、不到 10 KB）会原样塞进输入框，占满屏幕。1000 字符和 Pi 自己的编辑器一致。
标签是一个整体：光标跳过它，退格一次删掉整个标签，Ctrl+Z 一次恢复。
预览浮窗刚粘贴完、或光标停在标签上时，输入框上方显示前 3 行、⋮ (N more lines)、后 3 行。底边提示多了 click to view。
看全文单击浮窗，打开查看器。它就是现在点工具输出 … N more lines 打开的那个浮层：自动折行、行号、j/k/滚轮滚动、/ 搜索、w 折行开关、y 复制、q/Esc 关闭。
编辑查看器里按 e：打开编辑框（换掉输入框的位置），Enter 保存、Shift+Enter 换行、Esc 取消。保存后放回原位：仍够长就还是一个标签，否则变成普通文字。Ctrl+Z 一次恢复原标签。真实版里编辑框内 Ctrl+G 还能转到外部编辑器（原型不模拟）。
原地展开不变：光标在标签上按 Enter、双击标签、或刚粘贴完再粘贴一次，标签换成全文。
发出后用户消息超过 3 行时，原来只留一个 …。现在写成 … +N lines (click to view)，单击打开查看器看全文。

设计二：单击 task 行，看子任务在做什么

要素规则
入口单击 task、task_status、task_wait、task_cancel 的那一行。前台任务刚启动（还在排队）也能点。
任务页查看器里一页：顶部是状态、轮数、步数、正在做的事、会话文件路径；下面是子代理的对话（读它自己的会话文件）：它说的话、思考的一行、每个工具调用一行、每个结果最多 600 字。
实时任务在跑时页面自动刷新，最多每 250 ms 一次；停在末尾时跟着新内容往下走，往上翻后就不再跟随。
其他工具行不变：单击 $ git log … 这类行仍是原地展开 / 收起。

设计三：右下角 ◐ N tasks 可以点开

要素规则
入口单击右下角的任务计数；或输入 /tasks（列表）、/tasks <id>（直接进某个任务）。任务在跑、模型在输出时也能点。
列表页每个任务一行，最新的在上面：状态、id、预设名、轮数、正在做的事、任务开头。单击一行或按 Enter 进入任务页；Esc 回到列表，再按一次关闭。
只开一个再点一次底栏会换掉旧的浮层，不会叠出多个；切会话、退出时自动关闭。
不做在任务页里 steer 或取消子任务（仍由模型调用工具完成）。
