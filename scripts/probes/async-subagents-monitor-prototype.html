后台子代理与 Monitor

原型 v2（2026-11-06）。界面上不多造新概念：还是原来的工具行、原来的底栏和原来的 /tasks 弹窗，只是让子代理和后台监控能边跑边汇报、随时插话。

界面上只有 3 处变化

哪里怎么表现
1. monitor 工具行和 task 工具行长一个样：├─◆ monitor "盯 dev server 报错"。在后台盯着命令输出，抓到匹配的报错行或进程挂了才通知主对话；平时安静待着。
2. 后台消息随时插进来以前主对话在干活时，后台跑完的任务得等整轮结束才看得到。现在主对话每跑完一步工具，刚出炉的后台结果、子代理进度、或 monitor 抓到的报错就会作为一行 ◆ notify 接在下面，主对话顺手就能处理。
3. /tasks 和底栏把两者放一起右下角底栏计数把后台子代理和 monitor 算在一起（如 ◐ 2 tasks）。点一下底栏或输 /tasks，列表里同时列出子代理和 monitor，点进去看各自的对话或日志。

一、一轮完整演示（可点任务行或 /tasks 按钮）

主对话边聊边收后台消息 




演示流程：① 后台派出子代理改代码（独立 worktree），同时起一个 monitor 盯服务日志 → ② 主对话继续和你聊别的、读文件 → ③ 读文件刚结束，monitor 抓到报错、子代理跑完测试，两条消息直接插进当前回合 → ④ 点顶栏 /tasks（或直接点终端里的 task / monitor 行）看详情。



二、四个关键画面（固定 88 列）


A · 后台派出 task 和 monitor，主对话立刻空出来不阻塞当前对话


B · 主对话正在跑别的工具，后台结果顺手插进来不用等整轮结束


C · 给正在跑的子代理补一句话（默认顺延 vs 立即打断重来）按情况选
