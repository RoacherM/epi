# Review：在 Epi 里连续审查改动

[← 使用文档](README.md)

`/review` 打开一个整页的连续 diff：所有改动过的文件排在一页里，文件头之间直接是 diff，不用「打开文件 → 返回列表 → 打开下一个」。它是内置扩展 `epi:preview` 的一部分（同一扩展也提供 `/preview`），只在交互界面里加载，模型看不到它。设计见 [review-design.md](../review-design.md)。

## 打开与比较来源

| 输入 | 效果 |
|---|---|
| `/review` | 打开 agent 变更账里的改动 |

整页打开，`Esc` 关闭并回到对话。`s` 在三种比较来源之间切换，顶部始终写明在看哪两个版本：

| 来源 | 旧侧 | 新侧 | 说明 |
|---|---|---|---|
| agent 变更账 | 本次会话第一次改它之前 | 磁盘快照 | 只含 `write`/`edit` 触碰过的路径 |
| `Index → Working Tree` | 暂存区 | 工作区 | 包含 shell 和外部编辑，不归因于某个 agent |
| `HEAD → Index` | HEAD | 暂存区 | 即将提交的内容 |

未跟踪文件在 `Index → Working Tree` 里单列为新增。重命名保留旧、新两个路径。二进制、冲突、超大文件各自说明，不硬当普通文本。

## 键

| 键 | 作用 |
|---|---|
| `j` / `k`、PageUp/PageDown | 移动 |
| `]c` / `[c` | 下一个 / 上一个改动块（跨文件） |
| `.` / `,` | 下一个 / 上一个文件 |
| 回车 | 在 gap 上展开上下文，在文件头上折叠文件 |
| `c` | 给当前行写批注 |
| `m` | 标记文件已读（内容变了就变回未读） |
| `s` | 切换比较来源 |
| `R` | 重新读取，并重新检查批注锚点 |
| `B` | 把批注打包成草稿放回输入框（不自动发送） |
| `/`、`n` / `N` | 搜索 |
| `Esc` | 关闭 |

## 批注

批注记录：比较来源、文件路径、旧 / 新侧、行范围、引用文本，以及两侧内容的哈希。`R` 刷新后，只有当引用文本在新版本里唯一出现时才把批注移到新位置；片段消失或多处匹配就标成 `stale`，不静默贴到别的行。`B` 生成的草稿保留来源、版本哈希、路径、侧、行范围和引用，发不发由你决定。

批注以 custom entry（`epi.review.note.v1`）随会话保存，不进入模型上下文；重载时只从当前分支祖先链恢复。
