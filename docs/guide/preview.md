# Preview：在 MMP 里看文件

[← 使用文档](README.md)

`/preview` 是 MMP 自带的专用视图：不用离开 MMP 去开编辑器，就能浏览目录、看完整的文件、渲染后的 Markdown、图片和视频。它是内置扩展 `mmp:preview`，只在交互界面里加载，只注册这一个命令，模型看不到它。

当前版本：**0.1.0**（扩展有自己的版本号，和 MMP 的版本分开，见文末的更新记录）。

## 打开

| 输入 | 效果 |
|---|---|
| `/preview` | 在当前目录打开三栏浏览器 |
| `/preview src` | 在 `src` 目录打开 |
| `/preview docs/guide/preview.md` | 直接打开这个文件；关掉查看器后回到它所在的目录 |
| `/preview ~/Downloads/demo.mp4` | 直接播放这个视频 |

## 浏览器

三栏：上级目录 | 当前目录 | 预览。光标停在哪个条目上，右栏就预览哪个：目录显示它的内容，文本显示带行号和语法高亮的前几屏，图片和视频显示一帧画面。

| 键 | 作用 |
|---|---|
| `j` / `k`，`↓` / `↑` | 上下移动 |
| `l`、`→`、回车 | 进入目录，或打开文件的查看器 |
| `h`、`←` | 回上级目录 |
| `g` / `G` | 到顶 / 到底 |
| `Ctrl+D` / `Ctrl+U` | 翻半页 |
| `J` / `K` | 滚动右栏的预览 |
| `/` | 按名字过滤（回车确认，Esc 清除） |
| `.` | 显示或隐藏以 `.` 开头的文件 |
| `~` | 回到家目录 |
| 空格 | 标记或取消标记 |
| `i` | 把 `@路径` 插进输入框并关闭；有标记时插入所有标记的文件 |
| `q`、Esc | 关闭 |

鼠标：滚轮滚动，单击选中，双击打开，点击或拖动滚动条跳转。

## 查看器

| 文件 | 显示 | 键 |
|---|---|---|
| 文本、代码 | 行号加语法高亮 | `j`/`k` 滚动，空格 / `b` 翻页，`g`/`G` 到头尾，`w` 切换自动换行 |
| Markdown | 渲染后的样子 | 同上，`r` 在渲染和源码之间切换 |
| 二进制 | 十六进制 | 同文本 |
| 图片 | 原图，居中 | — |
| 视频、GIF | 播放，带进度条和音量波形 | 空格播放 / 暂停，`←`/`→` 跳 5 秒，`g` 回到开头；点画面暂停，点进度条跳转 |
| PDF、HEIC、Office 文档等 | macOS 的 Quick Look 缩略图 | — |

所有查看器里：`i` 把这个文件的 `@路径` 插进输入框并关闭，`q` 或 Esc 回到浏览器。

大文件只读前 4 MB，二进制只显示前 64 KB，超出时最后一行会说明。

## 要求

- **图片和视频画面**需要终端支持图形协议（kitty 协议或 iTerm2 协议，例如 Ghostty、kitty、iTerm2、WezTerm）。不支持时显示文字占位。
- **视频**需要本机装有 `ffmpeg`（出画面）、`ffprobe`（读时长和尺寸）和 `ffplay`（出声音）。没有时查看器会显示 `ffmpeg not found: install ffmpeg to view video`，其他功能不受影响。MMP 不自带也不安装它们。
- **Quick Look 缩略图**只在 macOS 上有。
- 设 `MMP_PREVIEW_NERD=1` 用 Nerd Font 图标显示文件类型。

## 和审查的关系

MMP 界面的分工是：对话区负责指挥和快速审查，需要细看时打开专用视图（[架构设计](../architecture.md) §3.3）。`/preview` 是第一个专用视图。0.1.0 是从文件和目录出发的；从"这次任务改了什么"出发（改动文件列表、diff、把批注发回给 agent）还没有做。
